## 🚀 HƯỚNG DẪN MỞ & SỬ DỤNG

1. **Xem trực tiếp:**  
   Nhấp đúp chuột vào file `index.html` trong thư mục dự án để mở ngay trên bất kỳ trình duyệt nào (Google Chrome, Microsoft Edge, Cốc Cốc, Safari, Firefox).
2. **Chỉnh sửa giá hoặc thông tin tour:**  
   Mở file `assets/js/main.js`, tìm mảng `TOURS_DATA`. Mỗi tour đều có cấu trúc rõ ràng (`name`, `price`, `itinerary`, `included`, `excluded`...) để thay đổi nội dung nhanh chóng.
3. **Kết nối Form vào Google Sheets hoặc CRM:**  
   Trong hàm `setupFormValidation()` tại `assets/js/main.js`, bạn chỉ cần thay thế đoạn `showSuccessReceiptModal(submissionData)` bằng một lệnh `fetch('YOUR_WEBHOOK_URL', { method: 'POST', body: JSON.stringify(submissionData) })`.
